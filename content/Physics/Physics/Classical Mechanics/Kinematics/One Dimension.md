#classicalMechanics 
**Kinematics** deals with the description of how objects move. The description of the motion of any object must always be given relative to some particular reference frame (external observer).

| Aspect       | Definition                                                                                                  | Value           | Type   |
| ------------ | ----------------------------------------------------------------------------------------------------------- | --------------- | ------ |
| Dispalcement | The distance of an object is the total length of the path traveled by an object, irrespective of direction. | any value       | vector |
| Distance     | The displacement of an object is the change in position of the object.                                      | always positive | scalar |
