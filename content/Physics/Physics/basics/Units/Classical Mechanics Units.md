#classicalMechanics 

| Unit                           | Unit Name                 | Symbol | Formula or Relation                |
| ------------------------------ | ------------------------- | ------ | ---------------------------------- |
| Velocity                       | metre per second          | m/s    | $v = \frac{\Delta s}{\Delta t}$    |
| Acceleration                   | metre per second squared  | m/s²   | $a = \frac{\Delta v}{\Delta t}$    |
| Force                          | newton                    | N      | $F = ma$                           |
| Momentum                       | kilogram metre per second | kg·m/s | $p = mv$                           |
| Impulse                        | newton second             | Ns     | $J = F \Delta t$                   |
| Work                           | joule                     | J      | $W = Fd \cos \theta$               |
| Power                          | watt                      | W      | $P = \frac{W}{t}$                  |
| Kinetic Energy                 | joule                     | J      | $KE = \frac{1}{2}mv^2$             |
| Gravitational Potential Energy | joule                     | J      | $PE = mgh$                         |
| Density                        | kilogram per cubic metre  | kg/m³  | $\rho = \frac{m}{V}$               |
| Pressure                       | pascal                    | Pa     | $P = \frac{F}{A}$                  |
| Stress                         | pascal                    | Pa     | $\sigma = \frac{F}{A}$             |
| Strain                         | dimensionless             | -      | $\varepsilon = \frac{\Delta L}{L}$ |
| Young’s Modulus                | pascal                    | Pa     | $E = \frac{\sigma}{\varepsilon}$   |
